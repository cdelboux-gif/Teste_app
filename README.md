# VitaPoint Mental Health MVP

Plataforma de monitoramento de saúde mental com onboarding, trilhas de testes psicológicos, check-ins, Health Score e insights assistidos por IA.

## Status atual

O repositório foi inicializado e está pronto para receber o código do MVP.

## Escopo inicial do MVP

- Cadastro e autenticação
- Onboarding do usuário
- Testes psicológicos e trilhas adaptativas
- Dashboard pessoal
- Check-in diário
- Diário emocional
- Health Score
- Insights de IA com limites de segurança
- Analytics de produto

## Stack planejada

- Mobile: React Native + Expo + TypeScript
- Backend: FastAPI + Python
- Banco: PostgreSQL
- Cache: Redis
- Analytics: PostHog
- Infra: Docker + AWS em etapa posterior
